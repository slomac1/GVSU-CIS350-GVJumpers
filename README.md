# GVJumpers

For this project we created an interactive world in which you can walk around and play an assortment of minigames. We started off with wanting to create a collection of games that you can play in whatever order or fashion the player wanted. But we also wanted it to be something more interactive for the player and not just opening an app and scrolling through games and picking one. So we turned that idea into a game itself. When you start the game you will find yourself stuck within a 2D carnival world. Your goal: collect 100 tickets so that you may leave the park. To collect tickets you can either go up to one of three game booths(Darts, Blackjack, Block Puzzle) to try and earn and gamble tickets, or you can head into the zombie invested tent and take the tickets off of undead corpses. Once you have 100 tickets head to the main gate and leave the park.
